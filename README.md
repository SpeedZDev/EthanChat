# Big Brother AI Assistant

Big Brother is a Streamlit-based AI assistant built with LangChain. It can answer general questions, search the web using Tavily, and read uploaded PDF files so users can ask questions about document content.

## Features

- Chat interface using Streamlit
- OpenAI chat model integration through LangChain
- Web search tool using Tavily
- PDF upload support
- PDF text extraction using PyMuPDFLoader
- Chat history stored with Streamlit session state
- Uploaded document content added into the AI context

## Tech Stack

- Python
- Streamlit
- LangChain
- OpenAI API
- Tavily Search
- PyMuPDF / PyMuPDFLoader
- python-dotenv
